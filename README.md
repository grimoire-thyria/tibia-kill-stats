# tibia-kill-stats

Kopia statystyk zabic Tibii dla The Hunting Grimoire.

- `data/<swiat>/<data>.json`: pelne statystyki z TibiaData, codziennie od
  27.10.2026, w formacie tibiamaps/tibia-kill-stats.
- `historia/<swiat>.json`: ubicia bossow od 23.08.2022 (z tibiamaps),
  dopisywane codziennie. Buduje ja raz "Zbuduj historie bossow".
- `bossy.json`: lista bossow apki do filtrowania.
